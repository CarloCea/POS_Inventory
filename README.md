How to run
1. Open a terminal in this main folder.
2. Install Node.js dependencies: `cd backend` then `npm install`
3. Install React dependencies: `cd frontend` then `npm install`
5. Run the Inventory Frontend: Open a new terminal, `cd frontend` then `npm start` (Runs on http://localhost:3000)
6. Run the POS Frontend: Open another new terminal, `cd frontend` then `npm run start-pos` (Runs on http://localhost:3001)
